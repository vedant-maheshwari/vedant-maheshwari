### ⚡ [RL Fine-Tuning for Faithful Financial Reasoning](https://github.com/vedant-maheshwari/Finance_reasoning_RL)
> End-to-end GRPO fine-tuning of **Qwen2.5-1.5B-Instruct** on FinQA

- 📈 Improved accuracy from **18.0% → 46.64%** via reward environment overhaul
- 🛠️ Fixed DSL parsing, binary comparisons, and reward saturation; achieved 55% Yes/No accuracy
- 🔍 Analysed RL failure modes: format drift & multi-hop retrieval without a retriever
