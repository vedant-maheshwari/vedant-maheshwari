## Research

Developing CAMEO — a quantitative score for evaluation-aware concealment in LLMs.

**Multilingual NLP** — AgriLex and a KCC crop-name dictionary spanning 22 Indian languages; unsupervised cross-lingual NMT via DAE and back-translation; bilingual lexicon induction reaching **96.3% F1 in Hindi** (100% recall). Benchmarked Gemma 2, Krutrim, Llama 3.1, Qwen 2.5, Param, Sarvam.

**Medical & evaluation AI** — MUSAN (Bayesian-uncertainty sparse-attention network for chest X-ray pneumonia detection); MedStat (13-microservice telehealth platform with RAG diagnostics, CNN-based AF detection, Hinglish-to-SOAP note generation).
